# Atividade de AEDs II - Ingressos

Projeto resolvido com as três questões propostas:

1. Ordenação dos ingressos por valor crescente e pelo nome do evento em ordem alfabética.
2. Implementação manual dos algoritmos Bubble Sort e Merge Sort.
3. Método `localizarPorValor`, que recebe valor mínimo e máximo, seleciona os ingressos dentro da faixa e retorna o resultado em ordem crescente de valor.

## Arquivos

- `src/Ingresso.java`: entidade Ingresso.
- `src/App.java`: menu, leitura do arquivo e implementação completa das questões.
- `ingressos.txt`: base de dados usada pelo programa.

## Como compilar

Na raiz do projeto:

```bash
javac -d bin src/*.java
```

## Como executar

Linux/macOS:

```bash
java -cp bin App
```

Windows:

```bat
java -cp bin App
```
